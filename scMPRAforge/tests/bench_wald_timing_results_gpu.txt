Notes:
  - 100% success rate on cohen + shendure (672/673 models, 1 ZINB failure)
  - Seelig timed out at 2h wall time. The 2 by_cell_type models with 1344 CRE
    columns dominate -- Jacobian is (N x 1345) per model. The 1344 by_cre
    models (2 columns each) are fast individually but numerous.
  - GPU utilization was 0-3%: the per-observation Jacobian is still sequential
    within each tape.jacobian() call. GPU helps via lower per-op dispatch
    overhead vs CPU eager (~10-20x faster than CPU).
  - @tf.function JIT did not improve GPU speed vs pure eager (both ~1.2s/model
    for cohen). The JIT benefit is bounded graph caching (no memory leak)
    rather than speed.
